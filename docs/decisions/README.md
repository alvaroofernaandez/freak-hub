# Registro de decisiones de arquitectura

Una decisión con alternativas reales se documenta aquí, no en un párrafo suelto
dentro de otro documento. El formato es corto a propósito: **contexto, decisión,
consecuencias**.

Un ADR no se edita cuando cambia de opinión: se escribe uno nuevo que sustituye al
anterior, y el viejo se marca como `Sustituido por ADR-XXXX`. La historia de por
qué se decidió algo vale tanto como la decisión.
