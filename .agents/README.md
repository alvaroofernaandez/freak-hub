# .agents/

Contexto adicional para agentes de IA. Las reglas operativas viven en
[`AGENTS.md`](../AGENTS.md), en la raíz, que es donde las buscan las herramientas.

Este directorio queda reservado para material que no cabe en un único fichero:
plantillas de prompt, notas de sesión o guiones de tareas repetitivas.

> **La dirección visual no vive aquí, vive en
> [`docs/design.md`](../docs/design.md)**, cerrada por
> [ADR-0008](../docs/decisions/0008-direccion-visual.md). Las decisiones de
> producto van con el resto de la documentación; este directorio es contexto
> para agentes, no un segundo sitio donde buscarlas.
